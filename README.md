## Overview

This repository is Bannysukumar's fork of [trustwallet/assets](https://github.com/trustwallet/assets). The original copyright and license stay with the upstream project.

Public fork of trustwallet/assets. The tree in this fork includes blockchains, cmd, dapps, internal.


What is actually in the repository: `.github/`, `blockchains/`, `cmd/`, `dapps/`, `internal/`. GitHub reports the primary language as Go.

Published site recorded on the repository: https://developer.trustwallet.com/assets/new-asset
